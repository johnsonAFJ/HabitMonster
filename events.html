What happens at each level

Built from the same table the game runs on, so it can't promise anything the game won't do.

    If something didn't happen

    • An event happens the moment its level is reached. If the level on screen is at or past an event's level and it isn't there, that's a bug.
    • Every level also raises every stat by 1, so the levels between the ones listed here are not empty.
    • Undoing a log takes its experience back, so it can drop a level and take that level's event with it. Log it again and it returns.
    • Missing a day never costs experience, only health. It just means the next event comes later.
    • Earliest means every habit logged every day, with 2 or more habits so the breadth bonus counts. Typical assumes about 28 XP a day.
    • This page reads the save on the device it's opened on. On a phone, open it from the link inside the Home Screen app, not from Safari, or it won't see his monster.
